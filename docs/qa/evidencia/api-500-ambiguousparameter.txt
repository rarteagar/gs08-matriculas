--- 3. Causa y arreglo sugerido (es el mismo patrón en los dos) ---

El patrón `AND (:propio IS NULL OR id <> :propio)` con `propio=None` deja a PostgreSQL sin
poder inferir el tipo del parámetro ("parameter $4"): el `IS NULL` no le da tipo y el `<>`
tampoco. Falla solo en el camino de **INSERT** (`propio=None`); en el `PUT` el valor llega
y la consulta funciona. Dos arreglos posibles, cualquiera de los dos sirve:

  a) castear el parámetro:  AND (CAST(:propio AS integer) IS NULL OR id <> CAST(:propio AS integer))
  b) armar la condición en Python:  sql = "..." + ("" if propio is None else " AND id <> :propio")
