DESVÍOS DECLARADOS (sustentados en el informe y en docs/decisiones.md)

• API en FastAPI (la consigna dice Express.js): cumple REST y GraphQL; decisión A-04, con
  plan B de un microservicio Express de un día si el docente lo exige por escrito.
• SPA con React 19 + Vite + Tailwind (la consigna menciona Next.js): React y Tailwind están
  cubiertos; Next.js no se usó porque la SPA es una aplicación de una sola página servida
  por nginx y no necesita renderizado en servidor.
• Kubernetes: manifiestos escritos y validados (11 objetos con kustomize), sin cluster real
  desplegado por la decisión de no instalar minikube en la máquina del grupo (A-02).
• Nube: VPS propio con Coolify + Traefik + Let's Encrypt en lugar de Netlify/AWS/Azure
  (esas plataformas no pueden hospedar la API ni la base de datos del proyecto).
